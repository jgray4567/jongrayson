# Kalshi Web Trader

**Category:** Application
**Status:** Active
**Main URL:** https://kalshi-web-trader.vercel.app

## Overview

Browser-based trading cockpit for Kalshi markets with server-side order signing. Full React/Next.js app with real-time market data, position management, and order execution.

## Tech Stack

- Next.js + React
- Kalshi API (server-side signing)
- Deployed via Vercel
