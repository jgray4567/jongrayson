# BogleAI

**Category:** Application

## Overview
Separate public Boglehead-style financial advisor app, distinct from JerryKnows AI and Web Team.

## Decisions
- Public and separate product.
- No login required.
- Anonymous browser session history.
- Default model: `meta-llama/llama-3.3-70b-instruct:free`.

## Notes
- Built around Boglehead philosophy-constrained advising.
- Includes portfolio analysis plus LLM advisor behavior.
- Intended domain: `https://bogleai.jerryknows.ai`.
