# Hermes Trader

**Category:** AI
**Status:** Active

## Overview

Single-loop autonomous paper-trading agent that persists memory as files, publishes pre-market intent before execution, journals plan-vs-execution divergence, and compares itself to three deterministic baselines. PAPER TRADING ONLY — `REAL_MONEY=false` is default.

## Safety

- `REAL_MONEY=false` is the default and required literal value for order submission
- Public demonstration artifact
- No real-money orders by default
