# GDP Mission Control

**Category:** Application
**Status:** In Development

## Overview

Starter web dashboard prototype for Grayson Design Partners operations. Tracks jobs pipeline, billing queue, alerts, utilization and revenue KPIs. Wired to Google Sheets for live data.

## Architecture

- `index.html` — Dashboard UI
- `app.js` — Dashboard logic
- `apps-script.gs` — Google Apps Script backend
- `styles.css` — Dashboard styling
- Wired to Google Sheet for live job/billing data
