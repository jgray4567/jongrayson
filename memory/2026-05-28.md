## Table & Tine Project Updates (2026-05-28)
- Configured iOS app and FastAPI backend to process physical recipe photos via Apple Vision OCR.
- The raw OCR text is sent to the backend for JSON formatting.
- The local Jerry model (3B) was struggling to output strict JSON due to a lack of fine-tuning, so we swapped the backend to route extraction requests to the Brainwave API (`inference.lyteforge.ai/v1`).
- Confirmed Brainwave API successfully parses messy OCR text (ingredients, steps, metadata) into the structured JSON required by the app.
