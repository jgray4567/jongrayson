- **AIP Dashboard (`jongrayson.com/intel/`) Updates**:
  - Found the *actual* actual root cause of the missing Pittsburgh Month selector text on Apple devices. 
  - There was a rogue, duplicated `.map-control-select` class in `styles.css` that was applying `padding: 8px 10px;` to an element explicitly locked to `height: 28px`. 
  - On Safari and Chrome/Mac, the `16px` of combined vertical padding inside a `28px` box forced the text node completely out of bounds vertically, causing it to be silently clipped/hidden by the browser. Stripped the rogue vertical padding (`padding: 0 10px;`), instantly restoring the text visibility.
