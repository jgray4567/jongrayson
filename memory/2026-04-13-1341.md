• api/signal-feed.php (now accepts ?taskId= and filters the feed by the taskId field)
• index.html (copy and build state updates)
• shell.js (tracks currentTaskIdFilter, updates the DOM data attributes, and intercepts clicks on the correlation chips to apply the filter)

Behavior

If you look at the Task Signal Correlation panel and see Air Watch · 1 signals, clicking that chip will:

1. Update the center-stage focus panel to show you are monitoring the specific task ID (Task: task-002)
2. Change the main headline to the actual human-readable name of the task (Live feed isolated to: Taiwan Strait Air Defense Zone)
3. Drop all unrelated signals from the live feed

Clicking anywhere else in that block clears the filter and restores the default view.
