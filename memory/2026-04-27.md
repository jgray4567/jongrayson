### Jerry / OpenMythos Server Architecture

- Jon asked about Beelink GTi15 + RTX 5060 Ti for Jerry — advised against it (64GB RAM, hard to upgrade, not unified memory)
- Decided on Apple Silicon priority: M3 Ultra 512GB (1st choice) or M4 Max 128GB + M4 Pro Mini 64GB (2nd choice)
- Apple Silicon unified memory > GPU docks for LLM inference
- Key insight: LLM inference doesn't cluster — can't split one model across machines. Each node must hold the full model.
- Cluster of Minis good for *serving* (load balancing), not for running bigger models
- 4× M4 Pro Mini 64GB = 256GB total but only ~30-35B per node, can't run 70B+

### Jerry Self-Improvement Architecture (Hybrid)

- **Autonomous loop (Jerry does itself):** Collect swap data from T&T users (anonymized) → Nightly LoRA fine-tuning on new data → Run evaluation benchmark suite → Safety checks (allergen accuracy, medical disclaimer, no hallucinated ingredients) → Queue for promotion
- **Supervised gate (me on heartbeat):** Review eval results 2-3x/day → Promote or reject model versions → Tune hyperparameters → Curate training data → Push config changes → Alert Jon if something needs human eyes
- **Human-in-the-loop (Jon):** Final call on anything medical/allergen → Approve major version bumps → Review flagged edge cases
- No model deploys to production without passing accuracy + safety benchmarks AND my sign-off
